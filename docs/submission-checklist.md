## 재현·통과 확인 4가지

### 1. 어디로 가나요
https://sktassign4-noticeboard-kt7g.vercel.app

text

### 2. 무엇을 하나요 (3단계 이내)
1. 화면 상단에서 오늘의 Top 5 키워드와 주 값(1위 키워드 출현 횟수)을 확인한다
2. "실패 재생" 버튼으로 5가지 실패 상태를 차례로 재생한다
3. "복구 재생 (T04-RECOVER-D2)"으로 상태가 fresh로 돌아오고 일별 기록이 1건 추가되는지 확인한다

### 3. 무엇이 보이면 통과
- 값·단위·출처·출처 시각·조회 시각·기준 시간대(Asia/Seoul)가 한 화면에 표시된다
- 실패 재생 시 마지막 정상값에 "오래된 값" 표시가 붙고, 각 실패마다 다른 `error_code`가 표시된다
- 복구 재생 후 상태가 fresh, error_code가 none으로 돌아오고 일별 기록이 1건 추가된다

### 4. 안 될 때
- 데이터가 안 오면 "오래된 값" 배지와 실패 사유가 표시되고, "다시 시도" 안내가 나타난다
- 원천 응답이 없으면 `public/data/`의 마지막 저장 기록이 화면에 남는다

## AI와 나의 판단 3줄

### AI에게 맡긴 일
HN Algolia API 조사, 데이터 계약·fixture·매니페스트 설계, 집계 규칙 초안, 화면 코드 작성, 실패 5종 처리 구조 제안

### 내가 판단한 일
데이터 주제 선정(HN 키워드 트렌드), 기술 스택 선택, KST 날짜 경계 규칙 확정, 배포 방식(Vercel) 결정, 고정 키워드 → 동적 Top 5 방식으로 변경 결정

### AI 제안을 따르지 않은 일
1. **고정 키워드(AI/security/LLM) → 동적 Top 5 집계로 전환**
   - AI는 처음에 3개 고정 키워드를 제안했으나, "왜 이 3개인가"의 근거가 약하고 "IT 최신 근황"을 표방하면서 고정 키워드는 그 자체가 최신이 아니라고 판단해 동적 Top 5로 변경
2. **`public-contract.json` 위치를 루트 → `public/`으로 변경**
   - AI는 처음에 저장소 루트에 두자고 했으나, 심사자가 URL로 직접 받아 SHA-256을 검증하려면 `public/`이 낫다고 판단해 이동
3. **초기 후보 OSV.dev/NVD → Hacker News Algolia로 변경**
   - AI는 처음에 보안 취약점 데이터(OSV.dev)를 추천했으나, "변동성이 눈에 잘 보이는가"라는 질문에 따라 Hacker News 키워드 트렌드로 전환
